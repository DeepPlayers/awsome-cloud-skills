## V3 核心特性总结

### 意图识别 vs 关键词提取

| 特性 | V2（关键词提取） | V3（意图识别） |
|------|----------------|---------------|
| **理解深度** | 表面拆分（支持计划 + 开通） | 深度理解（核心实体 + 操作条件） |
| **权重分配** | 平等权重（两个词同等重要） | 主次分明（核心词优先，条件词过滤） |
| **搜索策略** | 并行搜索，结果聚合 | 核心搜索，条件过滤 |
| **准确率** | 中等（结果可能不相关） | 高（符合用户真实意图） |
| **适用场景** | 简单关键词 | 复杂问题、操作流程 |

### 搜索策略选择

| 策略 | 适用场景 | 示例 | 优先级 |
|------|---------|------|-------|
| **A：单核心** | 简单关键词 | "支持计划" | 简单 |
| **B：核心+过滤** | 操作流程、方法 | "支持计划如何开通" | ⭐ 最常用 |
| **C：多核心并行** | 对比分析 | "SWAT和监控的区别" | 复杂 |
| **需确认** | 意图不明确 | "最佳实践有哪些" | 需交互 |

### 性能对比

| 指标 | V2 | V3 |
|------|----|----|
| API 调用 | 2-5 次（并行） | 1-3 次（核心）+ N 次（过滤） |
| 搜索速度 | < 2 秒 | < 2 秒 |
| 准确率 | 70% | 90%+ |
| 用户满意度 | 中等 | 高 |
| 结果相关性 | 中等（需要手动筛选） | 高（自动过滤） |
