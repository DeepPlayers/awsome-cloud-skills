# 钉钉知识库智能检索 Skill

智能搜索钉钉知识库文档，通过意图识别+权重搜索提升准确率。

## 概述

本技能为 AI 编程助手提供钉钉知识库的智能检索能力，支持意图识别、精准过滤、相关性评分等高级搜索功能。

## 核心功能

| 功能 | 说明 |
|------|------|
| 环境自动检查 | 执行前自动检测钉钉文档 MCP Server 是否已安装 |
| 智能意图识别 | 理解用户真实意图，区分核心实体和过滤条件 |
| 权重关键词策略 | 主次关键词区分，避免无效交叉聚合 |
| 精准过滤搜索 | 先搜核心词，再用条件词过滤，提升准确率 |
| 全知识库检索 | 搜索用户有权限的所有知识库，不限目录范围 |
| 相关性评分 | 基于标题匹配度、时间新鲜度、意图匹配综合评分 |
| 自动保存 | 结果超过 10 篇时，自动保存为本地 Markdown 文档 |
| 详细卡片 | 每个结果包含标题、类型、作者、时间、评分、链接等完整信息 |

## 使用示例

### 基础搜索

```
搜索钉钉知识库：支持计划如何开通
```

### 策略 B：核心+过滤搜索（最常用）

**场景**：支持计划续期流程

**意图识别**：
- 核心实体（权重高）：支持计划续期
- 操作条件（权重中）：流程

**执行流程**：
1. 搜索核心词："支持计划续期"
2. 过滤包含"流程"的文档
3. 按相关性评分排序

### 策略 A：单核心搜索

**场景**：什么是 SWAT

**意图识别**：
- 核心实体：SWAT

**执行流程**：
1. 直接搜索："SWAT"
2. 按相关性评分排序

### 策略 C：多核心并行搜索

**场景**：监控和告警的最佳实践

**意图识别**：
- 核心实体 1：监控
- 核心实体 2：告警
- 目标要求：最佳实践

**执行流程**：
1. 并行搜索"监控"和"告警"
2. 交叉对比结果
3. 按相关性评分排序

## 搜索策略

### 策略 A：单核心搜索

适用于：用户问题只包含一个明确的核心概念

```
搜索关键词：<核心实体>
```

### 策略 B：核心+过滤搜索 ⭐最常用

适用于：用户问题包含核心实体和操作条件

**第一步：搜索核心实体**
```
搜索关键词：<核心实体>
```

**第二步：过滤结果**
- 标题匹配：包含操作条件的文档（+20 分）
- 内容匹配：标题不包含但内容包含的文档（+10 分）
- 阈值控制：过滤后结果 < 3 篇时扩大范围

### 策略 C：多核心并行搜索

适用于：用户问题包含多个独立的核心概念

```
并行搜索：
- 关键词 1：<核心实体 1>
- 关键词 2：<核心实体 2>
```

## 意图识别策略

分析用户问题，识别以下要素：

1. **核心实体**（必选）：用户想了解的主要对象、概念、产品
   - 示例："支持计划"、"SWAT"、"监控"
   - 权重：**高**（用于主搜索）

2. **操作条件**（可选）：对核心实体的操作、流程、状态
   - 示例："开通"、"部署"、"续期"、"配置"
   - 权重：**中**（用于结果过滤）

3. **目标要求**（可选）：用户期望达成的目标或解决的问题
   - 示例："最佳实践"、"流程"、"方法"
   - 权重：**低**（用于评分参考）

## 相关性评分

评分维度：
- **标题匹配度**（40%）：关键词在标题中的匹配程度
- **时间新鲜度**（20%）：文档更新时间的新鲜程度
- **意图匹配**（30%）：与用户真实意图的匹配度
- **内容质量**（10%）：文档内容完整性和准确性
