1. 规则一：物理交互动词替换
当提示词出现以下高危险动词时【撞击、碰撞、反弹、坠落、翻滚、剐蹭、切入】，立即替换为环境反应描写【水花、尘土、碎片、光效、烟雾、阴影】
2. 规则二：时间顺序词解耦
- 避免连续叙事："镜头切换至.•然后..•最后.."
- 推荐使用并列枚举：“镜头从A、B、C角度呈现"
3. 规则三：结构化四要素框架
• 主体：［角色身份］+［关键道具］+［核心动作］
• 环境：［场景基调］+［光影条件］
• 特效：［运动效果］+［粒子效果］+［镜头语言］
• 风格：［画质标签］+［色调风格］
4. 规则四：数值描述处理
避免精确数值："倾斜45度"距离3米""持续2秒"
推荐方向性描述："大幅倾斜""近距离""短暂停顿"
